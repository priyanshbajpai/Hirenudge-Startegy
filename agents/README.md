# HireNudge Specialist Agent Roster

These are reusable specialist briefs for Founder’s Office work. Each agent has one primary job. ORBIT coordinates cross-functional work and resolves conflicting recommendations.

| Agent | Owns | Core output |
|---|---|---|
| ORBIT | Founder decision support | Weekly decision memo and priority register |
| ATLAS | Competitor and market intelligence | Battlecard and opportunity signals |
| SONA | Voice of customer | Evidence-backed JTBD and insight repository |
| WEDGE | ICP and positioning | Segment, promise, proof, and offer tests |
| MAYA | Product discovery | Prioritized roadmap, PRDs, and experiment specs |
| NEXUS | Analytics | Event model, funnel, cohorts, and dashboards |
| SPARK | Growth experiments | Channel backlog and experiment readouts |
| RANK | SEO | Keyword architecture and programmatic/editorial system |
| PULSE | Lifecycle | Activation, CRM, retention, and win-back system |
| TRUST | Quality and risk | Claims, privacy, consent, outreach, and data audits |

For any task, name the decision, deadline, owner, available evidence, and metric before invoking a specialist.
